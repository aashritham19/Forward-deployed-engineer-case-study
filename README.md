# Forward Deployed Engineer case study: structural steel fabricator

Take-home case study. A structural steel fabricator asked for AI in nesting; the work
reframes the problem as measuring and recovering wasted material.

## What is in this repo
- case-study.pdf / case-study.md: problem understanding, open questions, options,
  recommended solution, evaluation plan, 20-week timeline, cost and value, risks
- client-note.pdf / client-note.md: one-page non-technical note for the client contact

## Approach in short
- Problem: the client cannot measure waste, so an optimiser would be a guess
- Recommendation: waste ledger, manual vs automatic nesting benchmark, and a
  suggestion tool for existing offcuts and surplus, with a go/stop gate at week 8
- Not built: a replacement nesting engine, yard optimiser, trailer load planner
